Text messaging

Texts go out from Vercel through the n8n relay to voip.ms. Check connection tests each step the same way a real text travels; a test text goes out the same way too.

    Languages

    A language appears in the first message's menu once it's switched on, and it can only be switched on when every prompt has text in it. The menu label is how it's listed there. Names in their own script, like Español or 中文, are easiest to recognise but make that message a Unicode SMS, which holds less text; the preview shows the count.

    Prompts

    Saved text goes straight to the database the SMS signup reads. Words in braces, like {name}, are replaced with the real value when the message is sent, so keep them. After you save a change in English, Translate updates every other language from it.
